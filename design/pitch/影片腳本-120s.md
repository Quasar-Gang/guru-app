# 影片腳本 · 120 秒

繳交用的 2 分鐘產品影片。**無旁白**，純字卡 + 背景音樂，所以底下每一個字都要真的印在畫面上。

跟 `demo-腳本.md` 是兩份素材：那份是現場 5 分鐘上台用的（220 秒），這份是錄影用的。兩份都留著，不要合併。

- 載體：[Open Slide](https://open-slide.dev/) deck，`pitch/deck/slides/coach-2min/`
- 畫布：1920 × 1080，14 頁
- 視覺：mist 設計系統（跟站 1 一致）
- 停留時間公式：字數 ÷ 4 + 1.5 秒

## 閱讀負荷

無旁白的片子，唯一的節奏限制是**讀得完**。每頁的字分兩種：

- **必讀字** —— 看不到這句就看不懂這頁。字級 49 以上，**每秒不得超過 5 字**
- **質感字** —— 證明資料是真的，但不需要逐字讀（表格的非高亮列、節點名、署名、副標）。字級 24–35，不計入預算

底下每一頁都標了必讀字預算。改文案時先算這個，再決定要不要動秒數。

## 05 · 系統結構圖（13s · 必讀 28 字）

四段 band，左側色帶標號。節點與連線見 `deck/slides/coach-2min/` 的 diagram 元件。

```
① 蒐集    使用者 → Uploader → Profile
                      ⤺ Question Answering（追問迴路，虛線）

② 分析    Analyzer → Report（多面向）→ Recommender → Role Model（6 個形狀）

                        （accent 粗線，接回 Plan Engine）

多數工具停在第 ③ 段。第 ④ 段才是我們的位置。
```

**節點副標**

| 節點 | 副標 |
|---|---|
| Uploader | 資料處理 |
| Profile | 使用者特徵 |
| Report | 多個面向 |
| Role Model | 6 個形狀 |
| Milestone | 樹狀結構 |
| Task | 單層 |
| 痕跡 Trace | 行事曆／Notion／履歷／健康／工作／AI 對話 |

| 對帳引擎 | 四種結果 |
| 診斷 | 落後／失衡／隱形投入／錨點缺口 |

- ①②③ 是 `個人設計系統/styles/mist/pages/architecture.html` 既有的三段（也就是白板上那條管線），④ 是本次新增
- **那條回頭的 accent 粗線是整張圖唯一要讓評審看見的東西**——它把單向管線變成迴圈
- 動態：①②③ 在前 4 秒依序淡入，④ 在第 5 秒進場，回饋箭頭在第 8 秒最後畫出來
- 原圖底部的四則 12px 註解全部拿掉，影片裡讀不到
- 全片唯一的資訊密集頁，13 秒不能再短

# 語氣檢查

寫進畫面的每一句都要通過 `CLAUDE.md` 的三條：盤點不審判 · 預設懷疑目標 · 不承諾軟體做不到的事。

主敘事用會計語彙（對帳、歸戶、帳、稽核、體測、處方、錨點）。**打卡、習慣、連續天數這三個詞不准出現在任何一頁上。**

三頁共用時間軸：**2026-06-28 起草 → 2026-09-04 Q3 對帳 → 2026-09-30 季界 → 11/15 交件日**。
